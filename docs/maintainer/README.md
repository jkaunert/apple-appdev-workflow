# Maintainer documentation

This directory contains public contributor and release-maintainer records. It
is intentionally separate from the downstream installation README and the
generated Marketplace payload.

- [Release provenance](RELEASE_PROVENANCE.md) — public source and artifact
  lineage, hashes, and qualification boundaries.
- [Build Week retrospective](BUILD_WEEK_2026.md) — historical project context
  and the decisions that led to the hook-native release shape.

Do not add credentials, local machine paths, private transcripts, or unreleased
control-plane material here. Those belong in the private plugin source and
qualification workspace.
