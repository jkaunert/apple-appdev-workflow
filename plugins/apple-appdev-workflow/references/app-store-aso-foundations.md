# App Store ASO Foundations

Use behind `apple-appdev-workflow:apple-app-store-aso` for App Store listing strategy.

## Metadata roles
- App Name: highest-value visible positioning field.
- Subtitle: secondary visible search and positioning field.
- Promotional Text: conversion-oriented update surface, not the core search field.
- Keywords: compact hidden coverage field; keep it tight and non-repetitive.
- Description: conversion and clarity surface, not a place for noisy stuffing.

## Baseline
- Keep metadata readable and differentiated.
- Align title, subtitle, keywords, screenshots, and release context around one coherent positioning story.
- Prefer benefits and category clarity over generic buzzwords.
- Treat screenshot captions and ordering as conversion strategy, not an afterthought.
