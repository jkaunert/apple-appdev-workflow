# SwiftUI UI Patterns Index

Choose the narrowest reference that matches the task.

- `references/swiftui-app-wiring.md`: root shell, TabView, NavigationStack, router, and dependency graph setup.
- `references/swiftui-navigation-patterns.md`: navigation stacks, split views, deep links, title menus, and menu-bar concerns.
- `references/swiftui-modal-patterns.md`: sheets, overlays, toasts, scroll-reveal, and presentation ownership.
- `references/swiftui-list-form-grid-patterns.md`: lists, forms, settings, controls, grids, loading placeholders, and searchable surfaces.
- `references/swiftui-input-and-focus-patterns.md`: focus handling, input toolbars, keyboard flows, and input-heavy views.
- `references/swiftui-overlay-search-media-patterns.md`: searchable, media, haptics, matched transitions, and transient surfaces.

Selection rules:
- Start with app wiring for root-shell work.
- Use navigation patterns when routing or multi-column behavior is the primary concern.
- Use modal patterns when the task is about sheets, overlays, or transient secondary content.
- Use list/form/grid patterns for feed, settings, and structured data-entry UI.
- Use input/focus patterns for text-heavy or keyboard-driven flows.
- Use overlay/search/media patterns for richer interaction layers and content browsing.
