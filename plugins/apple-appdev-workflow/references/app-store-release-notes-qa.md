# App Store Release Notes QA

Use to validate App Store “What’s New” output.

## Checklist
- Every bullet maps to a real user-visible change.
- Internal-only work has been excluded.
- Duplicates or near-duplicates have been removed.
- Language is plain and free of internal jargon.
- The final list fits the release scope and storefront constraints provided.

## Ambiguity rule
- If a change might be internal-only, either confirm it first or describe it conservatively only if user impact is clear.
