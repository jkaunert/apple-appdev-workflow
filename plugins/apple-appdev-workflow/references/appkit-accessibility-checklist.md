# AppKit Accessibility Checklist

Use after AppKit accessibility changes.

## Verify
- Controls expose clear labels, roles, and help text where useful.
- Key-view loops and keyboard-first traversal reach every interactive control.
- Grouping and reading order make sense with VoiceOver.
- Tables, outline views, and custom controls announce meaningful state.
- Dynamic updates are announced or focused appropriately.
- Status is understandable without color alone.
