# App Store Screenshot Strategy

Use for screenshot sequencing and message hierarchy.

## Baseline
- Lead with the clearest user value in the first screenshot.
- Keep each screenshot focused on one message.
- Order screenshots as a concise narrative rather than a feature dump.
- Align screenshot messaging with title, subtitle, and promotional emphasis.

## Typical sequence
- Screenshot 1: primary value proposition
- Screenshot 2: strongest workflow or differentiator
- Screenshot 3: proof of ease, speed, or clarity
- Later screenshots: secondary features, trust, or depth

## Guardrails
- Do not overload screenshots with dense copy.
- Do not make screenshot captions contradict the actual product behavior.
