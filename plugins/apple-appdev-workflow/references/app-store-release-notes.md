# App Store Release Notes

Use behind `apple-appdev-workflow:apple-app-store-release-notes` for App Store “What’s New” text.

## Baseline
- Focus on user-visible improvements only.
- Prefer 5 to 10 short bullets for most releases unless the user asks otherwise.
- Use plain language and benefit-first wording.
- Translate technical implementation into user-facing outcomes.

## Preferred shape
- One sentence per bullet.
- Start with a concrete verb such as Added, Improved, Fixed, or Updated.
- Group by theme only when it improves readability.

## Guardrails
- Do not include internal tooling, refactors, or ticket references.
- Do not use long-form changelog structure.
