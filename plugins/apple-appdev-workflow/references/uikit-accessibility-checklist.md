# UIKit Accessibility Checklist

Use after UIKit accessibility changes.

## Verify
- Actionable elements expose correct labels, values, and traits.
- Grouping does not create duplicate announcements or hide controls.
- Screen changes and async updates are announced when needed.
- Dynamic Type scales correctly, including custom fonts.
- Hit areas are comfortable and custom controls remain discoverable.
- State is understandable without color.
- Primary journeys remain usable with VoiceOver.
