# Reasoning Error Patterns

Use for practical error checking during decision review.

## Common patterns
- Hidden assumptions: a conclusion depends on premises no one stated or tested.
- False dichotomy: the reasoning assumes only two options when more exist.
- Ad hoc rescue logic: new caveats are added only to save the preferred option from criticism.
- Contradiction: parts of the argument undermine each other.
- Evidence/conclusion mismatch: the evidence supports a weaker claim than the conclusion states.
- Overclaiming from convenience: a choice is defended because it feels cleaner, simpler, or familiar rather than because it best solves the problem.
- Proves too much: if the argument were valid, it would also justify clearly bad choices.
- Ambiguous success criteria: the decision cannot be evaluated because winning conditions were never made concrete.
- Unfalsifiable rollout claims: the plan contains no concrete signal that would tell us it is failing.

## Review stance
- Surface only the patterns that materially affect the decision.
- Prefer actionable criticism over rhetorical point-scoring.
