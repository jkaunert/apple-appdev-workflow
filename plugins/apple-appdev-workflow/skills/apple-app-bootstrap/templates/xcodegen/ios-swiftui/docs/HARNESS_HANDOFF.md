## Validation Handoff

After opening the generated project, use XcodeBuildMCP as the primary
validation path:

1. Discover the project and scheme.
2. Set session defaults for the generated iOS project and simulator target.
3. Run simulator build validation.
4. Run simulator test validation.
5. Capture runtime or screenshot evidence only when a feature or release lane
   requires it.

Raw `xcodebuild` is a fallback for real MCP gaps, not the default validation
path.
